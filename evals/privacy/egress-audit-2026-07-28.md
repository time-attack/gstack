## Residual risk (NEEDS_REVIEW items)

1. **Telemetry anonymous-tier semantics + raw visited domain** (browse). security.ts:471 claims "anonymous → local only" but gstack-telemetry-sync uploads anonymous-tier events (stripping only installation_id), and `security_url_domain` ships the raw domain of the attacked page. Behind default-off opt-in, but consent text ≠ behavior. Fix: make anonymous genuinely local-only (`[ "$TIER" = "anonymous" ] && exit 0` in sync) or fix comment + tier docs; hash or eTLD+1-truncate the domain. (bin/gstack-telemetry-sync:117, browse/src/security.ts:490)
2. **Welcome-page font CDNs** (browse). Every headed start fetches fonts from Google/Fontshare — a default-on third-party request the user did not direct (IP/UA only). Fix: self-host or system font stack in welcome.html. (welcome.html:7, server.ts:2509)
3. **Braintrust upload on key presence** (cli-utilities). Ambient BRAINTRUST_API_KEY alone flips benchmark-content upload on, contradicting PRIVACY.md:28. Fix: require explicit `--upload` flag or `braintrust_upload` config in addition to the key. (lib/model-benchmark/braintrust-eval.ts:114)
4. **Autoplan silent Codex dispatch** (skills). "run codex (always yes)" is auto-decided; `codex_reviews` defaults enabled; plan/diff content reaches OpenAI with CLI-auth presence as effective consent and no redact scan. Fix: persisted per-repo first-dispatch consent or flip default to disabled; add redact scan-at-sink. (autoplan.md:149, :317)
5. **codex.md / claude.md missing redact scan-at-sink** (skills). Branch diffs ship to OpenAI/Anthropic unscanned, while spec/ship/cso all scan their external sinks. Fix: insert `{{REDACT_INVOCATION_BLOCK:codex}}` (and equivalent) before dispatch. (codex.md:194, claude.md:201)
6. **iOS legacyResolve6 fallback** (ios-daemon). The c-ares fallback can send `<device-name>.coredevice.local` as a unicast DNS query to the LAN/upstream resolver — device-name metadata, no user content, no gate. Fix: delete the fallback (mDNS path covers real hardware) or env-gate it. (devicectl.ts:67-73)
7. **Orphaned design binary** (design). Untracked 63MB design/dist/design still embeds api.openai.com endpoints; key-gated and unreferenced, but the dead DESIGN_SETUP resolvers would mark it DESIGN_READY if a stale template regenerated. Fix: delete design/dist/ + upgrade migration; delete generateDesignSetup/generateDesignMockup and their index.ts registrations; fix stale setup:31 help text. (design/dist/design; scripts/resolvers/design.ts:729; index.ts:66)

## What changed since PRIVACY.md was written

- **"A key present in the environment is not consent" (PRIVACY.md:28) is enforced for Context.dev but not everywhere.** Three audited paths treat credential/auth presence as standing consent: Braintrust upload (braintrust-eval.ts:114), autoplan's automatic Codex dispatch with `codex_reviews` defaulting enabled (autoplan.md:149, :317), and the /review outside-voice dispatches (codex.md:194, claude.md:201). These postdate or sit outside the doc's stated principle.
- **Telemetry tier semantics drifted from documented intent.** The "anonymous → local only" claim in code (security.ts:471) no longer matches sync behavior, and `security_url_domain` uploads browsing-derived data under an opt-in PRIVACY.md frames as "minimal legacy telemetry" (gstack-telemetry-sync:117).
- **Welcome-page font fetches fall outside the contract's carve-out.** PRIVACY.md sanctions "navigation requests to sites the user directs it to"; the auto-opened /welcome page's CDN fetches are undirected default-on egress (welcome.html:7).
- **Bootstrap `preview` fetches the release manifest before install consent.** Metadata-only and user-invoked (judged compliant), but PRIVACY.md does not explicitly state this pre-consent manifest GET — worth documenting (runtime-bootstrap.mjs:167).
- **Two surfaces PRIVACY.md-era docs still describe were deleted.** design/src/ (9053324a) and extension/ (ab4e9ae5) are gone — consistent with PRIVACY.md's contract state, but project CLAUDE.md still lists the extension and `setup:31` still advertises design/pdf/diagram capabilities; both are stale relative to the shipped tree.
